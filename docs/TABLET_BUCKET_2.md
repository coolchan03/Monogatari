# Tablet and Large Screen Finish

Search uses a two-pane results/preview layout at 840dp and wider. Phone search preserves its existing navigation. Manga, books, videos and audio are supported by the unified search. Public catalog results preview metadata and open official links by explicit tap.

Details pages use the existing full information-and-chapters side-by-side resource in 840dp portrait as well as landscape. Library shows one readable list column alongside its detail pane, with retained selection through refresh and window changes.

Device QA: check portrait 800dp, portrait 840dp, landscape 1280dp, phone 393dp, foldable resizing, system bars, themes, book/video results, long-press selections, physical keyboard and screen readers.

No database migration, source IDs, credentials, packages or SDK changes.
