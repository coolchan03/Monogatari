# Kitsune originals

Full-resolution mascot artwork supplied by the owner on 2026-10-19 (`PACK_README.txt` is the pack's own notes).
These files are the master copies; the app uses 512px exports made by `scripts/kitsune/export_stickers.py`.

| reading | Books, welcome sheet, empty history, downloads, Books library tab | chibi_kitsune_reading_a_book.png |
| search | Search/explore empty states | curious_kitsune_with_magnifying_glass.png |
| celebrate | Suggestions, Video library tab | joyful_teal_eyed_kitsune_sticker.png |

| collection | Favourites, related titles, Manga library tab | winking_fox_with_treasured_books.png |
| news | News form (Discover/News) | chibi_fox_spirit_reporter_sticker.png |
| audio | Audio library tab | whimsical_kitsune_headphone_sticker.png |
| human | Hidden Easter egg (seven quick taps) | flirty_teal_accented_kitsune_greeting.png |
